Protection of Personal Information

We do not provide personally identifiable information to third parties. We take the utmost care in managing personal information and handle it as described below.

Usage Analysis

This application (Android/iOS) uses Firebase Analytics by Google Inc. to analyze usage and improve our services. Through this, Google Inc. may collect user device information (such as Advertising IDs and generated UUIDs) and operation logs, but this does not include personally identifiable information. For more information on how Google handles data, please refer to Google's Privacy Policy.

The flow Web Lite browser experience (try.html) also uses Google Analytics (GA4) via the same Google Analytics property to measure page views and in-browser interactions. This may set a _ga cookie in your browser. No personally identifiable information is collected.

In addition to standard analytics, we collect the following behavioral data as custom events to better understand how users interact with the app and web experience:

  • Task completion events (including session duration in minutes and whether a color label was used)
  • Task abandonment events
  • Feature settings state (ambient sound enabled, screen always-on enabled)
  • Web Lite interactions (timer start/finish/abandon, ambient sound toggle, download button clicks)

This data is collected in aggregate and does not identify individual users.
